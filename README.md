# Very Own Repo

A public notebook and long-form blog written from ongoing work in this repository.

## Start here

**[Meaning Is Not Everything](posts/001-meaning-is-not-everything.html)** — the first essay, and the beginning of the thread.

The rule of the repository is simple: substantial writing is published as a readable blog post, whether it arrives as 500 words, 1,000 words, 2,000 words, or some other natural length. Posts should stand on their own, but the homepage keeps a clear path from the beginning so a new reader can enter without knowing the history of the work.
